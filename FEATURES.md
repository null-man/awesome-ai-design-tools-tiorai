# Features

What this repository does today, what is committed, and what is only an idea. The three
headings are not the same promise, and the difference is the point of the file.

## Available

Shipping now, in this release.

- **48 tools across 10 stages**, grouped by the design job rather than by software category.
- **Two complete editions.** English and Arabic, same entries, same order, descriptions written in each language rather than translated.
- **An editable-output rule.** Anything that returns a flattened image where a file is needed was excluded, however good the output looks.
- **Open format and self-hosting called out**, because a design file you cannot open in five years is a design you will redraw.
- **Every link resolved over HTTP** before release, and pricing and platform labels from the portfolio's shared vocabularies.

## Planned

Committed. These have a decided shape and will land; nothing is listed here to make the
repository look busier than it is.

- **A pass every quarter on the interface and design-to-code categories**, which are moving faster than the rest of the list.
- **Entries for tools the issue tracker asks about**, which is better evidence of a gap than guessing at one.

## Ideas

Not committed, and possibly never. Listed because a contributor may want to argue for one, or
build it. Opening an issue about any of them is welcome.

- **A training-corpus column** for the generators, saying whether the data is licensed. The fact that decides commercial use, and unstated by most vendors.
- **An export-format column.** It is the rule the list is built on and it would need re-checking every release to stay true.
- **A section on accessibility tooling.** Underserved, important, and thin enough today that it would be four entries pretending to be a category.

---

Anything absent from all three lists is absent on purpose. See
